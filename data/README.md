# data/

## resultados_piloto_porto_alegre.csv

Tabela consolidada com o indicador Razão Serviços/Nó calculado para os 12 bairros
da amostra-piloto. Colunas descritas em `docs/dicionario_de_dados.md`.

Gerado a partir do notebook em `notebooks/GEO_Equidade_Porto_Alegre.ipynb`. Não
edite este arquivo manualmente — refaça a execução do notebook se precisar
atualizar os resultados.

## Origem e atribuição dos dados

- **OpenStreetMap** — © contribuidores do OpenStreetMap, disponibilizado sob
  Open Database License (ODbL). Extrato distribuído pela Geofabrik
  (https://download.geofabrik.de).
- **IBGE/SIDRA** — população por bairro, usada para composição da amostra.
- **Malha geométrica dos municípios brasileiros (IBGE)** — catalogada no
  Portal Brasileiro de Dados Abertos
  (https://dados.gov.br/dados/conjuntos-dados/malha-geometrica-dos-municipios-brasileiros),
  usada para delimitação e conferência do recorte municipal de Porto Alegre
  (código IBGE 4314902).

Este arquivo CSV é um dado derivado de bases sob ODbL (OpenStreetMap). A
distribuição preserva a atribuição acima, conforme exigido pela licença.
